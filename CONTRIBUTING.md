# Contributing

This repository distributes the Scoop manifest for STH.

Submit changes through a pull request. Explain the intended change and how it was verified. Do not include credentials, customer data or private configuration. Report vulnerabilities using [SECURITY.md](SECURITY.md), not public issues.

Package files are generated by the release pipeline. Fix recurring generation issues in the source configuration; a manual edit can be overwritten by the next release. Verify that artifact URLs use HTTPS under the official Skills-transfer-hub/sth-releases repository, versions match, and hashes match the intended release. Do not execute proposed binaries merely to review a manifest.

Maintainers should review changes to workflows, package URLs, checksums and publishing behavior before merging. Use isolated validation environments for untrusted contributions.
